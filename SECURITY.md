# Seguridad

El mantenimiento se centra en la versión actual de la rama principal. Es un proyecto personal, sin un plazo de respuesta garantizado.

Para informar de una vulnerabilidad, utiliza **Security → Advisories → Report a vulnerability** en GitHub cuando esté habilitado. Si no aparece esa opción, puedes abrir una incidencia que solicite un canal privado, sin incluir detalles de explotación, datos personales ni credenciales. El mantenedor podrá coordinar el envío privado.

Incluye la versión o commit afectado, una descripción del impacto y pasos de reproducción con datos de prueba. No publiques una prueba de explotación ni datos de otras personas en una incidencia pública.

Las partidas se guardan localmente. Editar el propio `localStorage` o el reloj para alterar una racha no se considera una vulnerabilidad: no hay cuentas, clasificación competitiva ni validación remota de resultados.
